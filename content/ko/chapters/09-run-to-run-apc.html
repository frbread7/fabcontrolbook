런투런 APC와 EWMA 제어기 수학

학습 목표

런투런(R2R) 첨단공정제어(APC)는 완료된 로트 또는 웨이퍼의 계측이나 장비 측정을 이용해 외란을 보상하고 다음 런 사이에 레시피 입력을 조정합니다. 이 장에서는 기본 EWMA 제어기를 전개하고 가정과 안정성 절충을 설명하며, 출력이 제약조건, 측정 이력, 사람의 거버넌스와 어떻게 연결되는지 다룹니다. 제어기가 있다는 사실만으로 검증되지 않은 공정의 자동 보정이 안전해지는 것은 아닙니다.

모든 제어 갱신에는 입력 로트·웨이퍼, 장비와 챔버, 레시피 개정판, 측정 응답, 계측 시각과 교정, 제어기 상태, 선택된 레시피, 제약 상태, 작업자 승인, 결과 런 식별자를 보존하십시오. 지연된 결과를 사이에 다른 로트가 처리되었는데도 ‘최신’ 런에 조용히 연결해서는 안 됩니다.

EWMA R2R 모델

스칼라 공정 응답을 yk = a + b uk + dk + εk라 합시다. u는 조정 가능한 레시피 입력, b는 국소 공정 이득, d는 외란, ε는 측정 노이즈입니다. 선형 관계는 명시된 운전 범위 내 국소 근사입니다. 별도로 모델링하지 않으면 비선형성, 상호작용, 액추에이터 동특성, 이득 변화를 포함하지 않습니다.

부호 있는 목표 오차 qk = ytarget − yk를 관측한 뒤 보정 잔차를 q̄k = λqk + (1−λ)q̄k−1로 평활합니다(0 < λ ≤ 1). 이는 물리적 외란 dk의 추정치가 아니라 보정 방향을 정하는 목표 오차의 EWMA입니다. 단순 갱신은 uk+1 = uk + Kq̄k입니다. 국소 이득 b가 양수이면 양의 K가 보정 부호입니다. 양의 외란으로 출력이 목표보다 높아지면 q는 음수가 되어 입력을 낮춥니다. 실제 공정 이득이 다른 부호를 가지면 제어기 부호를 반대로 정하고, 적용 전에 알려진 교란으로 확인하십시오.

작은 λ는 노이즈를 부드럽게 하지만 계단형 외란에 느리게 적응합니다. 큰 λ는 더 빠르게 반응하지만 레시피 움직임에 더 많은 노이즈를 전달합니다. 제어기 이득을 높이면 보정 시간이 줄 수도 있으나 지연이 있을 때 진동하거나 계측 노이즈가 증폭될 수 있습니다. 지연은 측정 결과가 더 오래된 레시피에 해당함을 뜻합니다. 제어기는 런 연결을 보존하고 갱신 큐를 안전하게 관리해야 합니다. 결측 또는 순서가 뒤바뀐 측정에서는 가짜 값을 만들지 말고 상태를 유지하면서 데이터 품질 조건을 발생시키십시오.

입력 제한 umin ≤ uk ≤ umax, 갱신당 최대 변화, 변화율 제한, 공정 안전 한계를 포함하십시오. 포화 상태에서는 잔차 오차가 남고 선형 보상 가정이 무효가 될 수 있습니다. 액추에이터가 경계인데 내부 추정치가 계속 움직일 때의 적분기 포화 방지 또는 상태 초기화 규칙을 정의해야 합니다. 제품·공정 규격 경계를 넘지 않아야 하지만 규격은 장비 안전 운전 한계를 대체하지 않습니다.

다변량 공정에서 응답과 레시피 벡터는 y = A u + d로 연결됩니다. 행렬 A의 조건이 나쁘거나 식별되지 않으면 역보정은 위험합니다. 안전하게 설계한 입력 변화로 모델을 식별하고 불확도를 추정하십시오. 관측 상관만으로 인과를 추론하지 마십시오. 피드포워드는 결과 전에 이용 가능한 외란 측정을 쓰고 피드백은 처리 후 측정 응답을 씁니다. 지연과 고장 모드가 다릅니다.

풀이 예제

완전히 합성한 정규화 공정을 사용해 봅시다. 목표는 0, 이득은 b=2 응답 단위/입력 단위, 지연은 없고 5번째 런부터 +1 응답 단위 계단 외란이 생깁니다. 기준 계산에서는 측정 노이즈가 0입니다. λ=0.5, K=1/b=0.5이면 평활된 부호 있는 목표 오차가 관측 잔차 쪽으로 절반씩 이동합니다. 첫 변화 뒤 잔차는 음수이므로 다음 레시피 갱신은 입력을 낮춥니다. 이 가정의 이득과 지연에서는 후속 갱신이 출력 오차를 줄입니다. 부호와 갱신 순서를 확인하는 결정론적 점검 사례이며 물리적 외란을 직접 추정하지 않습니다.

여기에 1런 측정 지연과 표준편차 0.2의 노이즈를 더해 보십시오. 제어기가 오래된 오차를 받으며 런을 잘못 연결하거나 이득을 높이면 과보정할 수 있습니다. 고정 난수 시뮬레이션에서 출력 오차, 레시피 이동, 제약 위반 횟수, 안정화 시간을 비교합니다. 시드, 갱신 규약, 노이즈 모델, 런 수를 보고하십시오. 시뮬레이션 결과는 가정에 조건부이지 생산 성능 약속이 아닙니다.

제약된 제어기라도 배포하기 전에는 해당 운전 영역의 이득 부호와 크기, 계측 누락, 포화, 수동 홀드와 롤백, 계측 경로 적격성, 레시피 한계를 독립 검토해야 합니다. 단계적 승인과 갱신 후 결과 모니터링을 적용하십시오. 통계적 관리 한계는 공정 거동을 나타내고 제품 규격 및 장비 안전 한계는 서로 다른 결정을 지배합니다.

한계와 엔지니어링 보호 장치

EWMA R2R은 충분히 안정된 이득, 정확한 런 매칭, 의미 있는 목표, 공정에 적절한 외란 모델을 가정합니다. 자기상관 계측 오차, 상호작용 입력 다수, 레시피 전환, 정비 초기화는 단순 계산을 무효화할 수 있습니다. 입력이 점점 극단적으로 움직여 출력이 안정돼 보일 수도 있으므로 출력과 액추에이터 궤적을 모두 감시하십시오.

이 교육 모델을 실제 웨이퍼 레시피 권고로 사용하지 마십시오. 생산 적용에는 공정 책임자 승인, 안전한 설계 실험, 모델 검증, 장비 인터록, 사이버보안 및 변경 관리, 추적성, 안전 동작, 사람의 판정 절차가 필요합니다. 실리콘이나 팹 검증을 주장하지 않습니다.

복습 질문

  1. 스칼라 선형 R2R 모델의 가정을 밝히고 국소 이득이 부족한 경우를 설명하십시오.
  2. λ는 노이즈 억제와 계단 응답 간에 어떤 절충을 만듭니까?
  3. 지연 계측 결과를 실제 처리 런에 연결해야 하는 이유는 무엇입니까?
  4. 레시피 입력이 포화되면 어떤 일이 생기며 어떤 포화 방지 정책을 정해야 합니까?
  5. 관리 한계, 제품 규격, 장비 안전 경계를 구분하십시오.
