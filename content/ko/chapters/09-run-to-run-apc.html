런투런 APC와 EWMA 제어기 수학

학습 목표

런투런(R2R) 첨단공정제어(APC)는 완료된 로트 또는 웨이퍼의 계측이나 장비 측정을 이용해 외란을 보상하고 다음 런 사이에 레시피 입력을 조정합니다. 이 장에서는 기본 EWMA 제어기를 전개하고 가정과 안정성 절충을 설명하며, 출력이 제약조건, 측정 이력, 사람의 거버넌스와 어떻게 연결되는지 다룹니다. 제어기가 있다는 사실만으로 검증되지 않은 공정의 자동 보정이 안전해지는 것은 아닙니다.

모든 제어 갱신에는 입력 로트·웨이퍼, 장비와 챔버, 레시피 개정판, 측정 응답, 계측 시각과 교정, 제어기 상태, 선택된 레시피, 제약 상태, 작업자 승인, 결과 런 식별자를 보존하십시오. 지연된 결과를 사이에 다른 로트가 처리되었는데도 ‘최신’ 런에 조용히 연결해서는 안 됩니다.

EWMA R2R 모델

기억 효과가 없는 스칼라 교육용 공정에서 물리적 출력을 xk = c₀ + b uk + δk, 관측 결과를 yk = xk + ηk라 둡니다. u는 런 k에 적용한 입력, b의 단위는 입력 단위당 응답 단위, δ는 응답 단위의 외란, η는 계측 오차입니다. 상수 c₀는 오프셋이며 실습의 공정 기억 매개변수 a와 다릅니다. 이 식은 정의된 운전 범위의 국소 근사이지 식별이 끝난 팹 공정 모델이 아닙니다.

결과가 이용 가능해지면 부호 있는 목표 오차 qk = ytarget − yk와 q̄k = λqk + (1−λ)q̄k−1를 계산합니다(0 < λ ≤ 1). 이는 보정 잔차를 평활할 뿐 물리적 외란을 실측한 값이 아닙니다. 결과가 즉시 도착하면 다음 런의 명령은 uk+1 = uk + Kq̄k입니다. bK가 양수이면 높은 출력에서 q가 음수가 되어 다음 입력을 낮추는 보정 부호를 가집니다. 실제 공정 이득의 부호와 크기는 승인된 안전한 식별 실험으로 확인해야 합니다.

지연이 없는 정확한 특수 사례. c₀+δ가 일정하고 계측 노이즈와 포화가 없으며 λ=1이면 xk+1−ytarget = (1−bK)(xk−ytarget)입니다. |1−bK|<1, 즉 0<bK<2에서만 점근 수렴합니다. 경계 bK=2에서는 진폭이 줄지 않는 교대 응답입니다. 이 조건은 평활, 공정 기억, 계측 지연, 추가 입력 적용 지연, 노이즈, 입력 제한에는 적용되지 않습니다.

실습의 런 규약. 별도의 정규화 공정은 x[k]=a x[k−1]+(1−a)(δ[k]+u[k−1−da])를 사용하며, a는 출력 기억, 공정 이득은 양의 단위 이득, da는 추가 입력 적용 런 지연입니다. 결과 y[k]=x[k]+η[k]는 런 k 뒤에 생성되고, 계측 지연이 m이면 그 시점에 y[k−m]만 이용할 수 있습니다. EWMA와 제한된 명령 갱신은 해당 출처 런을 사용하며, 첫 결과가 도착하기 전에는 명령을 유지합니다. 계산된 u[k]는 런 k에 영향을 줄 수 없습니다. 아래의 해석적 b=2 예제와 실습의 단위 이득은 의도적으로 다른 정규화입니다.

작은 λ는 노이즈를 부드럽게 하지만 계단형 외란에 느리게 적응합니다. 큰 λ는 더 빠르게 반응하지만 레시피 움직임에 더 많은 노이즈를 전달합니다. 제어기 이득을 높이면 보정 시간이 줄 수도 있으나 지연이 있을 때 진동하거나 계측 노이즈가 증폭될 수 있습니다. 지연은 측정 결과가 더 오래된 레시피에 해당함을 뜻합니다. 제어기는 런 연결을 보존하고 갱신 큐를 안전하게 관리해야 합니다. 결측 또는 순서가 뒤바뀐 측정에서는 가짜 값을 만들지 말고 상태를 유지하면서 데이터 품질 조건을 발생시키십시오.

입력 제한 umin ≤ uk ≤ umax, 갱신당 최대 변화, 변화율 제한, 공정 안전 한계를 포함하십시오. 포화 상태에서는 잔차 오차가 남고 선형 보상 가정이 무효가 될 수 있습니다. 액추에이터가 경계인데 내부 추정치가 계속 움직일 때의 적분기 포화 방지 또는 상태 초기화 규칙을 정의해야 합니다. 명령은 승인된 레시피 범위 안에 있어야 하고, 예측 및 실측 제품 응답은 해당 규격과 별도로 비교해야 합니다. 제품 규격은 장비 안전 운전 한계를 대체하지 않습니다.

다변량 공정에서 응답과 레시피 벡터는 y = A u + d로 연결됩니다. 행렬 A의 조건이 나쁘거나 식별되지 않으면 역보정은 위험합니다. 안전하게 설계한 입력 변화로 모델을 식별하고 불확도를 추정하십시오. 관측 상관만으로 인과를 추론하지 마십시오. 피드포워드는 결과 전에 이용 가능한 외란 측정을 쓰고 피드백은 처리 후 측정 응답을 씁니다. 지연과 고장 모드가 다릅니다.

좁은 화면에서는 표를 가로로 밀거나 포커스한 뒤 화살표 키로 읽을 수 있습니다. 출력 1, 0.5, 0, −0.25, −0.25는 목표를 지나가므로 절대 오차가 단조 감소하지 않습니다. 일정한 외란과 비포화 가정에서는 두 상태 점화식의 특성다항식이 r²−r+0.5=0이고, 근 0.5±0.5i의 크기는 √0.5<1입니다. 이 특정 평활 루프는 진동하면서 점근 감쇠하지만, 이 결과를 지연·포화·이득 오식별 공정에 옮길 수는 없습니다.

이제 각 계측 결과에 1런의 지연을 둡니다. 런 5 종료 시 이용 가능한 것은 여전히 런 4의 결과이므로 오차 0에 따라 런 6 명령이 유지됩니다. 런 6 종료 시 런 5 결과가 도착하여 런 7 명령을 처음 바꿀 수 있습니다. 추가 입력 적용 지연은 다른 대기열입니다. 결과는 지금 도착해도 방금 계산한 명령은 더 나중의 런에 적용됩니다. 실습에서는 두 지연을 따로 조절하고 어느 출처 런이 제어기를 갱신했는지 확인할 수 있습니다. 시드와 노이즈 수준(예: 응답 단위 표준편차 0.2)을 밝히고 출력, 입력 이동, 포화를 비교하십시오. 유한 시뮬레이션 궤적을 일반 안정성 증명이나 생산 성능 추정치로 사용해서는 안 됩니다.

제약된 제어기라도 배포하기 전에는 해당 운전 영역의 이득 부호와 크기, 계측 누락, 포화, 수동 홀드와 롤백, 계측 경로 적격성, 레시피 한계를 독립 검토해야 합니다. 단계적 승인과 갱신 후 결과 모니터링을 적용하십시오. 통계적 관리 한계는 공정 거동을 나타내고 제품 규격 및 장비 안전 한계는 서로 다른 결정을 지배합니다.

한계와 엔지니어링 보호 장치

EWMA R2R은 충분히 안정된 이득, 정확한 런 매칭, 의미 있는 목표, 공정에 적절한 외란 모델을 가정합니다. 자기상관 계측 오차, 상호작용 입력 다수, 레시피 전환, 정비 초기화는 단순 계산을 무효화할 수 있습니다. 입력이 점점 극단적으로 움직여 출력이 안정돼 보일 수도 있으므로 출력과 액추에이터 궤적을 모두 감시하십시오.

이 교육 모델을 실제 웨이퍼 레시피 권고로 사용하지 마십시오. 생산 적용에는 공정 책임자 승인, 안전한 설계 실험, 모델 검증, 장비 인터록, 사이버보안 및 변경 관리, 추적성, 안전 동작, 사람의 판정 절차가 필요합니다. 실리콘이나 팹 검증을 주장하지 않습니다.

복습 질문

  1. 스칼라 선형 R2R 모델의 가정을 밝히고 국소 이득이 부족한 경우를 설명하십시오.
  2. λ는 노이즈 억제와 계단 응답 간에 어떤 절충을 만듭니까?
  3. 지연 계측 결과를 실제 처리 런에 연결해야 하는 이유는 무엇입니까?
  4. 레시피 입력이 포화되면 어떤 일이 생기며 어떤 포화 방지 정책을 정해야 합니까?
  5. 관리 한계, 제품 규격, 장비 안전 경계를 구분하십시오.
