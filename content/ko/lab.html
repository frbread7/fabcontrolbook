대화형 제어 실험실

한 번에 하나의 가정을 바꾸고, 근거를 살펴본 뒤, 엔지니어링 결론을 내리기 전에 각 모델의 한계를 확인하세요.

검증 범위

브라우저 모델은 독립적으로 작성한 결정론적 학습 구현입니다. 방정식과 일부 기준 계산은 해석적으로 확인하고 경계 조건도 테스트합니다. 팹 데이터에 맞춰 보정하지 않았고 실리콘에서 검증하지 않았으며 양산 의사결정에 사용할 수 없습니다. 생성 데이터는 모두 합성입니다.

실험 A · 합성 몬테카를로

SPC 검출 성능

동일한 독립 가우시안 관측값에서 표준화 Shewhart, EWMA, 양측 표 형식 CUSUM 검출을 비교합니다. 안정 구간 뒤에 변화가 시작되며, 몬테카를로 요약은 설정한 관측 구간 안의 검출과 같은 길이의 무변화 기준선 전체 구간에서 발생하는 알람 확률을 추정합니다. 무변화 결과는 전체 구간에서 한 번 이상 알람이 발생할 확률입니다. 변화 주입 시행의 첫 알람은 변화 전, 변화 후, 또는 신호 없음으로 나뉘며 전체 시행을 분할합니다. 관리 상태 오경보 목표에 맞춰 동일하게 보정한 비교가 아니므로 동일 ARL 비교가 아닙니다. 유한 관측 구간은 평균 런 길이(ARL)가 아닙니다.

zₜ = μₜ + εₜ, εₜ ~ N(0, σ²); Eₜ = λzₜ + (1−λ)Eₜ₋₁; C⁺ₜ = max(0, C⁺ₜ₋₁ + zₜ − K), C⁻도 동일한 방식.

EWMA 한계는 유한 표본 분산에 따라 목표값부터 넓어집니다. 설명용 설정은 Shewhart ±3σ, L = 3, K = 0.5σ, h = 5σ, 초기값 0입니다. 보편적인 관리도 설계 권고가 아니라 비교 설정입니다. 관측 잡음 표준편차를 바꾸면 기준 σ=1에 고정된 한계와 의도적인 분산 불일치가 생깁니다.

아직 실행하지 않았습니다. 데이터는 모두 합성입니다.

가정: 알려진 안정 기준선, 독립 정규 관측값, 고정 관리도 매개변수. 자기상관, 부분군 설계, 매개변수 추정과 재시작 방식은 실제 검출 성능을 바꿉니다.

실험 B · 합성 챔버 트레이스

FDC 신호 분석

레시피 단계가 명시된 합성 다중 채널 순서를 살펴봅니다. 각 단계와 채널에서 알려진 분산을 사용한 평균 z 통계량, 정규이론 근사의 산포 z 통계량, OLS 기울기 z 통계량을 계산합니다. 결측과 단계 맥락 불일치는 별도로 표시합니다. 통계 특징 중 하나가 임계값을 넘거나 데이터·맥락 결함이 있으면 단계를 표시합니다. 투명한 학습 규칙이며 학습된 분류기나 근본 원인 판정이 아닙니다.

z̄ⱼ = (x̄ⱼ−μⱼ,기준)/(σⱼ,기준/√n); zₛ,ⱼ ≈ (sⱼ−σⱼ,기준)/(σⱼ,기준/√(2(n−1))); zᵦ,ⱼ = β̂ⱼ/(σⱼ,기준/√Sxx). max(|z̄|,|zₛ|,|zᵦ|) > τ, 결측 > 0, 맥락 불일치 > 0이면 표시.

아직 트레이스가 없습니다. 신호 단위는 정규화된 교육용 지수입니다.

가정: 고정 분산을 아는 독립 정규 잡음, 고정 단계 경계, 표준오차 근사. 채널·단계에 걸친 36개 특징 비교는 서로 상관되며 다중검정 보정이 없어 한 단계 이상 오경보 확률은 단일 검정의 꼬리 확률보다 높을 수 있습니다. 단계 표시는 고장 원인 식별이 아닙니다. 결측·맥락 규칙은 결정론적 표시입니다. 단계 정렬, 센서 보정, 고장 라벨과 판정 한계는 현장 데이터 평가가 필요합니다.

실험 C · 이산 배치 모델

런투런 APC

정규화 이득 g = 1로 고정한 제한된 1차 공정에 계단 외란을 가합니다. 측정한 목표 오차의 EWMA가 런 사이에서 액추에이터 보정량을 조정하며, 액추에이터/런 지연 dₐ와 계측 결과 지연 m을 구분합니다. 런 k 종료 시 y[k−m]만 사용할 수 있고(k−m ≥ 0), 첫 결과 전에는 추정값과 명령을 이전 값으로 유지합니다. 합성 점화식이며 실제 장비 검증이 아닙니다.

xₖ = a xₖ₋₁ + (1−a)[dₖ + uₖ₋₁₋dₐ]; k−m ≥ 0이면 ēₖ = λyₖ₋ₘ + (1−λ)ēₖ₋₁ 및 uₖ = clip(uₖ₋₁ − Kc ēₖ, ±Umax); 아니면 ē와 u를 유지합니다.

아직 실행하지 않았습니다. 출력과 액추에이터는 정규화 교육 단위입니다.

가정: 일정한 양의 공정 이득, 알려진 단조 방향, 1차 런 동특성, 계단 외란, 제한된 보정, 레시피별 상호작용 없음. 실제 장비 제어기의 안정성을 식별하는 실험이 아닙니다.

실험 D · 합성 알람 부담

제조 알람 전략

임계값·지속 횟수·감시 신호 수·k-of-n 규칙 변화에 따른 알람 확률과 이상 감지를 비교합니다. 공통 정규 성분으로 표본 시점별 채널 간 등상관을 반영하며 시간 상관은 없습니다. 주입 시행의 첫 알람(사건 전, 사건 후, 없음)은 전체 시행을 분할합니다. 합성 결과는 외부 알람 권고가 아닙니다.

zᵢₜ = √ρ cₜ + √(1−ρ) εᵢₜ; 신호 k개 이상이 m개 연속 표본 동안 τ를 넘으면 알람.

아직 실행하지 않았습니다. 추정값은 이 합성 시나리오의 몬테카를로 결과입니다.

가정: 가우시안 표준화 잡음, 등상관, 고정 임계값, 알려진 표본 시점의 사건, 독립 시행. 유한 구간에서 추정한 오경보 비율은 장기 알람률이나 팹 기준값이 아닙니다.
