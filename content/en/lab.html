Interactive control laboratories

Change one assumption at a time, inspect the evidence, and read each model limit before drawing an engineering conclusion.

Validation boundary

These browser models are original, deterministic teaching implementations. Their equations and selected numerical cases are analytically checked and tested for boundary behavior. They are not fitted to fab data, validated on silicon, or suitable for production decisions. Every generated dataset is synthetic.

Lab A · Synthetic Monte Carlo

SPC detection performance

Compare standardized Shewhart, EWMA, and two-sided tabular CUSUM detection on the same independent Gaussian observations. A shift begins after a stable baseline period. Monte Carlo summaries estimate detection within the selected horizon and alarm probability across a matched-duration no-shift horizon. The false-alarm result is the probability of one or more alarms anywhere in the full no-shift reference horizon, not a pre-change segment statistic.

zₜ = μₜ + εₜ, εₜ ~ N(0, σ²); Eₜ = λzₜ + (1−λ)Eₜ₋₁; C⁺ₜ = max(0, C⁺ₜ₋₁ + zₜ − K), C⁻ analogously.

For the EWMA, limits expand from the target according to its finite-sample variance. The illustrative settings use a 3σ Shewhart limit, L = 3, K = 0.5σ, h = 5σ, and start-up at zero. These are comparison settings, not universal chart-design recommendations. The observed-noise SD control intentionally compares data with changed variance against limits fixed to baseline σ=1.

Assumptions: known stable baseline, independent normal observations, fixed chart parameters. Autocorrelation, subgroup design, parameter estimation, and restart logic change real chart performance.

Lab B · Synthetic chamber trace

FDC signal intelligence

Inspect a synthetic multichannel sequence with explicit recipe phases. For each phase and channel, the activity computes a known-variance mean z statistic, an approximate normal-theory dispersion z statistic, and an OLS slope z statistic. Missingness and phase-context mismatch are reported separately. A phase is flagged if any statistical feature crosses the selected threshold or a data/context defect occurs; this transparent teaching rule is not a trained classifier or a root-cause result.

z̄ⱼ = (x̄ⱼ−μⱼ,ref)/(σⱼ,ref/√n); zₛ,ⱼ ≈ (sⱼ−σⱼ,ref)/(σⱼ,ref/√(2(n−1))); zᵦ,ⱼ = β̂ⱼ/(σⱼ,ref/√Sxx). Flag if max(|z̄|,|zₛ|,|zᵦ|) > τ, missingness > 0, or context mismatch > 0.

No trace yet. Trace units are normalized teaching indices.

Assumptions: iid Gaussian noise within a fixed known phase baseline, fixed phase boundaries, and approximate standard-error formulas. A per-feature threshold is not adjusted for testing many channels/phases, so any-phase false-alarm probability can be substantially higher than a single-test tail probability. Missing/context rules are deterministic flags. Site-specific alignment, sensor calibration, fault labels, and decision limits require local evaluation.

Lab C · Discrete batch model

Run-to-run APC

A bounded first-order plant with fixed normalized gain g = 1 receives a step disturbance. An EWMA of measured target error updates an actuator correction between runs. The model makes the one-run metrology/control cycle and any additional run delay explicit.

xₖ = a xₖ₋₁ + (1−a)[dₖ + uₖ₋₁₋d] ; ēₖ = λ(yₖ−r) + (1−λ)ēₖ₋₁ ; uₖ = clip(uₖ₋₁ − Kc ēₖ, −Umax, Umax).

Assumptions: constant positive plant gain, known monotone direction, first-order run dynamics, step disturbance, bounded correction, and no recipe-specific interactions. This exercise does not identify controller stability for an actual tool.

Manufacturing alarm strategy
